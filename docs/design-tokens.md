# 디자인 토큰 (My Fit)

색·모서리·글자 크기·굵기·간격은 `src/app.html` 맨 위 `:root`의 CSS 변수(토큰)로만 씁니다. 새 CSS를 쓸 때 숫자나 색을 직접 넣지 말고 아래 토큰을 쓰세요. `tests/suites/tokens.js`가 이 규칙을 검사합니다.

## 색 (밝은 테마 / 어두운 테마)
| 토큰 | 용도 | 밝게 | 어둡게 |
|---|---|---|---|
| `--bg` | 화면 배경 | #ffffff | #111214 |
| `--card` | 카드·시트 | #ffffff | #17191c |
| `--soft` | 옅은 면(입력칸, 스테퍼) | #f5f6f8 | #1b1d21 |
| `--line` | 테두리·구분선 | #ebecee | #27292d |
| `--fg` | 본문 글자 | #141516 | #f1f2f4 |
| `--muted` | 보조 글자 | #8a8d93 | #8f9298 |
| `--accent` | 강조(링크, 선택) | #2f6bff | #5b8bff |
| `--accent-fg` | 강조색 위 글자 | #ffffff | #ffffff |
| `--accent-soft` | 강조 옅은 면 | #e9efff | #1d2a4d |
| `--pri` | 주 버튼 배경(어두운 테마에서도 흰 글자 대비 유지) | #2f6bff | #2f6bff |
| `--good` / `--warn` / `--hl` | 좋음·주의·하이라이트 | #1f9d6a / #d9822b / #e5484d | 같음 |
| `--danger` / `--danger-ink` | 삭제 배경 / 위험 글자 | #e5484d / #d9403c | 같음 |
| `--c-stretch` `--c-warmup` `--c-dynamic` `--c-strength` `--c-cardio` `--c-cooldown` | 운동 유형 배지 | | 같음 |
| `--equip`, `--bm-*` | 그림 엔진(도구, 바디맵) | | 테마별 |
| `--shadow-1` | 선택된 세그먼트 그림자 | 0 1px 2px rgba(0,0,0,.08) | 같음 |
| `--scrim` | 시트 뒤 어두운 막 | rgba(0,0,0,.35) | 같음 |

어두운 테마 값은 두 곳(시스템 다크 `@media`, 직접 고른 `[data-theme="dark"]`)에 똑같이 들어갑니다. 하나를 바꾸면 다른 하나도 바꾸세요(테스트가 비교).

## 모서리
`--r-sm` 8px · `--r-md` 10px · `--r` 12px(카드) · `--r-lg` 14px · `--r-pill` 999px. 원은 `50%`. 2·3·6·7·9·24·32px은 한두 곳에만 쓰는 모양이라 숫자로 둡니다.

## 글자
크기: `--fs-3xs` 10 · `--fs-2xs` 11 · `--fs-xs` 12 · `--fs-sm` 13 · `--fs-md` 14 · `--fs-base` 15(본문) · `--fs-lg` 16 · `--fs-xl` 17 · `--fs-2xl` 18 · `--fs-3xl` 20 · `--fs-4xl` 22 (px). 타이머 같은 큰 숫자(64·76px)는 숫자로 둡니다.
굵기: `--fw-normal` 400 · `--fw-semi` 600 · `--fw-bold` 700.
설정의 "글자 크기: 크게"는 `html[data-text="lg"]{zoom:1.15}`로 전체를 키우므로 토큰 값은 바꾸지 않습니다.

## 간격 (gap)
`--sp-xs` 4 · `--sp-sm` 6 · `--sp-md` 8 · `--sp-lg` 12 · `--sp-xl` 16 (px). 2·3·10·20px은 숫자로 둡니다.

## 누르는 영역
버튼·토글·칩은 44×44px 이상(`tests/suites/touch.js`). 보이는 크기를 키울 수 없으면 투명한 `::before`로 넓힙니다.
